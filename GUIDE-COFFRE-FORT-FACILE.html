Les Dossiers de Votre Coffre-Fort

Pas besoin de vous casser la tête à créer des dizaines de dossiers. Votre coffre est déjà rangé en 5 zones indispensables :

1
01 · Moi (Qui vous êtes)
Contient votre fiche Mon-Mode-d-Emploi.md et vos Mes-Objectifs.md. C'est ici que vous notez vos priorités pour que Claude et ChatGPT vous connaissent par cœur.
2
02 · Projets (Ce que vous construisez)
Chaque projet a sa propre fiche (ex: Exemple-Mon-Projet.md). Vous y retrouvez l'état d'avancement, vos idées et vos prochaines étapes à réaliser.
3
03 · Contacts (Votre carnet d'adresses)
Une fiche par personne importante (partenaires, clients, amis). Plus de carnet d'adresses perdu : notez-y ce que vous vous êtes dit la dernière fois.
4
04 · Ressources (Vos inspirations)
Vos notes de lecture, articles intéressants, citations et liens utiles que vous souhaitez garder sous la main.
📥
La Boîte de Réception (Pour les jours pressés)
Vous n'avez pas le temps de classer ? Jetez votre note ou document brut dans _Boite-de-Reception/. Demandez plus tard à l'IA : « Range ma boîte de réception » et elle s'occupe de tout !

Les 3 Phrases Magiques à Dire à Claude ou ChatGPT

Ce que vous dites Ce que fait l'IA automatiquement Résultat
« Bonjour » ou « On reprend » Ouvre Memoire.md et vous rappelle le contexte exact du dernier échange. Zéro temps perdu à se remettre dans le bain.
« Note ça : [votre info] » Cherche si une note existe déjà, la met à jour sans faire de doublon. Votre coffre-fort reste propre et à jour.
« On s'arrête » Met à jour la mémoire, résume ce qui a été fait et note la suite. Tout est prêt pour la prochaine session.

Installation Pas-à-Pas (100% Clics Visuels)

Suivez ces 3 étapes simples sans jamais ouvrir de terminal ou taper de code :

1
Créer votre coffre privé sur GitHub (1 clic)
Rendez-vous sur le modèle officiel : https://github.com/AlexB0311/mon-vault-starter
Cliquez sur le bouton vert Use this template puis sur Create a new repository.
Donnez un nom (ex: mon-coffre-fort), cochez Private (privé) et validez.
2
Le récupérer sur votre ordinateur (via GitHub Desktop)
Téléchargez l'application gratuite GitHub Desktop (desktop.github.com).
Connectez-vous à votre compte GitHub, cliquez sur Clone a repository, sélectionnez votre coffre et choisissez où le stocker sur votre disque dur.
(Astuce encore plus simple sans compte : cliquez sur Code > Download ZIP sur GitHub et décompressez le dossier).
3
Ouvrir votre coffre dans Obsidian
Téléchargez et ouvrez Obsidian (obsidian.md).
Cliquez sur « Ouvrir un dossier comme coffre » (icône de dossier) et choisissez le dossier de votre coffre-fort.
C'est tout ! Vous arrivez directement sur votre Tableau-de-Bord.md.

Synchroniser sur son Smartphone (Optionnel mais Magique)

📱
Vos notes dans votre poche : Installez l'application Obsidian sur votre téléphone (iOS ou Android). Activez le plugin gratuit Obsidian Git ou utilisez l'application Working Copy sur iPhone pour retrouver l'intégralité de vos notes hors-ligne partout où vous allez.

Le Prompt à Copier-Coller dans Claude et ChatGPT

Copiez ce texte et collez-le dans votre discussion sur chatgpt.com ou claude.ai (ou configurez-le dans un Projet Claude ou dans vos Instructions personnalisées ChatGPT) :

Tu es mon partenaire et assistant de confiance opérant sur mon Coffre-fort numérique personnel (mon vault Obsidian).

Ton rôle est de m'aider à faire avancer mes projets et de garder en mémoire le fil de notre travail sans jamais être amnésique.

VOICI NOS RÈGLES DE COLLABORATION :

1. DÉMARRAGE :
Quand je te dis « Bonjour » ou « On reprend » :
- Lis immédiatement notre fichier central Memoire.md (et applique REGLES-IA.md).
- Réponds-moi en une seule phrase amicale en me rappelant sur quoi nous travaillions la dernière fois et la prochaine étape prévue.
- Ne me demande JAMAIS de te réexpliquer ce qui est déjà noté dans le coffre.

2. PENDANT QU'ON DISCUTE :
- Quand je dis « Note ça : [info] », vérifie d'abord si une note existe déjà avant d'en créer une nouvelle (évite les doublons).
- Si une information ou un document n'a pas de place évidente, range-le dans le dossier _Boite-de-Reception/.
- Ne supprime jamais de note : si une chose est finie ou obsolète, déplace-la dans le dossier _Archives/.
- Tu as 6 Super-Pouvoirs documentés dans le dossier Skills/ (démarrage, ranger-boite, plan-d-action, synthese-express, redaction-impact, cloture). Dès que ma demande y correspond, applique la méthode correspondante.

3. CLÔTURE DE SESSION :
Quand je dis « On s'arrête », « Fin de session » ou « C'est bon pour aujourd'hui » :
- Mets à jour le fichier Memoire.md avec :
  1. Ce que nous avons accompli aujourd'hui.
  2. L'état actuel de mes projets.
  3. La prochaine action recommandée pour notre prochaine discussion.
- Termine par un mini-résumé de 3 lignes.

Si tu as bien compris, confirme-le moi simplement et commençons !
