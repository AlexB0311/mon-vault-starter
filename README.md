# 🔐 Mon Coffre-Fort Personnel (Starter Kit Vault)

> Votre espace de travail privé et souverain, sans abonnement, synchronisé sur tous vos appareils et piloté en toute simplicité par **Claude** et **ChatGPT**.  
> **Zéro ligne de commande. 100% accessible à tous.**

---

## ✨ Pourquoi ce Coffre-Fort ?

- 🔒 **Vos données vous appartiennent :** Vos notes sont de simples fichiers texte (`.md`) stockés sur votre ordinateur. Même sans connexion Internet, tout fonctionne.
- 💰 **100% Gratuit à vie :** Pas d'abonnement mensuel à payer (Obsidian et GitHub sont gratuits).
- 🤝 **Vos IA ne sont plus amnésiques :** Grâce au fichier `Memoire.md`, Claude et ChatGPT se souviennent exactement de vos projets d'une discussion à l'autre.
- 📱 **Dans votre poche :** Synchronisé automatiquement sur votre ordinateur et votre smartphone.

---

## 🚀 Comment Démarrer en 3 Minutes (Zéro Ligne de Commande)

### Étape 1 : Créer votre Coffre Privé sur GitHub (1 clic)
1. En haut à droite de cette page GitHub, cliquez sur le gros bouton vert **« Use this template »** (Utiliser ce modèle) puis sur **« Create a new repository »**.
2. Donnez-lui un nom (ex: `mon-coffre-fort`).
3. Cochez **Private** (votre coffre doit rester privé pour vous seul).
4. Cliquez sur **« Create repository »**.

---

### Étape 2 : Récupérer le dossier sur votre ordinateur
- **Méthode simple avec GitHub Desktop (Recommandée) :**
  1. Téléchargez l'application gratuite [GitHub Desktop](https://desktop.github.com).
  2. Cliquez sur *File > Clone repository*, choisissez votre nouveau coffre et choisissez où le ranger sur votre ordinateur.
  3. Dès que vous modifiez une note, GitHub Desktop vous permet de sauvegarder en un seul clic !
- *OU Méthode ultra-rapide sans compte GitHub :*  
  Cliquez sur le bouton vert **Code > Download ZIP**, et décompressez le dossier sur votre ordinateur.

---

### Étape 3 : Ouvrir dans Obsidian
1. Téléchargez l'application gratuite **Obsidian** sur [obsidian.md](https://obsidian.md) (disponible sur Windows, Mac, Linux, iPhone et Android).
2. Cliquez sur **« Ouvrir un dossier comme coffre »** (*Open folder as vault*) et sélectionnez votre dossier.
3. Vous arrivez sur votre [[Tableau-de-Bord]] !

---

### Étape 4 : Connecter Claude ou ChatGPT
1. Ouvrez votre conversation habituelle sur [chatgpt.com](https://chatgpt.com) ou [claude.ai](https://claude.ai).
2. Copiez-collez le texte qui se trouve dans [[PROMPT-CLAUDE-ET-CHATGPT]].
3. Dites simplement **« Bonjour »**. L'IA lit votre mémoire et vous guide pour la suite !

---

## ⚡ Les 3 Phrases Magiques au Quotidien

| Ce que vous dites à Claude ou ChatGPT | Ce que l'IA fait immédiatement |
|---|---|
| **« Bonjour »** ou **« On reprend »** | L'IA lit `Memoire.md` et vous rappelle où vous en étiez sans rien vous faire répéter. |
| **« Note ça : [votre idée/contact/projet] »** | L'IA range l'information au bon endroit sans créer de doublon. |
| **« On s'arrête »** ou **« C'est bon pour aujourd'hui »** | L'IA met à jour la mémoire pour la prochaine fois et vous fait un résumé en 3 lignes. |

---

## 🛠️ Les 6 Super-Pouvoirs Inclus (Skills)

Votre coffre contient 6 compétences prêtes à l'emploi dans le dossier `Skills/` :
1. **Démarrage** (*« Bonjour »*) : Reprend le contexte en 1 seconde.
2. **Ranger la boîte** (*« Range ma boîte de réception »*) : Classe les brouillons accumulés.
3. **Plan d'action** (*« Fais-moi un plan d'action pour [X] »*) : Découpe une idée en 3 étapes concrètes.
4. **Synthèse express** (*« Résume-moi ce document »*) : Extrait les 3 idées fortes et la leçon de vie.
5. **Rédaction impact** (*« Rédige un message pour [X] »*) : Écrit un email percutant et personnalisé.
6. **Clôture** (*« On s'arrête »*) : Met à jour la mémoire et prépare la prochaine session.
