# 🎯 Skill : Plan d'Action Express

## Quand l'activer ?
Quand l'utilisateur partage une nouvelle envie ou idée et dit :
- *« Fais-moi un plan d'action pour [X] »*
- *« Comment je commence ce projet ? »*
- *« Aide-moi à structurer cette idée »*

## Ce que doit faire l'IA (Claude ou ChatGPT) :
1. **Clarifier l'objectif en une phrase percutante :** Quel est le résultat concret recherché ?
2. **Découper en 3 étapes chronologiques simples :**
   - **Étape 1 : Cadrage (Aujourd'hui) :** Ce qu'on peut faire en moins d'une heure.
   - **Étape 2 : Prototype / Action (Cette semaine) :** Le premier livrable visible.
   - **Étape 3 : Validation (Ce mois-ci) :** Comment mesurer si ça fonctionne.
3. **Créer ou mettre à jour la fiche du projet** dans `02-Projets/<Nom-du-Projet>.md`.
4. **Mettre à jour la table des projets dans `Memoire.md`**.
5. **Proposer la toute première action immédiate** :
   > *« Fiche créée dans 02-Projets/ ! La toute première étape pour démarrer dès maintenant : [Action simple]. On la fait ensemble ? »*
